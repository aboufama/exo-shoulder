The morphology with the smallest gap on the bench right now. Gap = points short of the bench targets; lower is better, 0 means every target is met. Optimisation inside each morphology

Each line is one morphology's own sweep: the best gap found so far after each configuration it tried, as its own agent measured it, on one shared scale. A line that goes flat early means tuning inside that type has stopped paying off. A hollow ring at a line's end is the verifier's re-measured gap.

Claimed vs re-measured

↓ lower gap is better

An adversarial verifier re-measures each promising claim on the same bench. Hollow dot: the gap the morphology's own agent claimed. Filled dot: the gap the verifier measured. A long move to the right means the claim did not hold.

Pipeline

How far the morphologies have got. Each stage counts every morphology that reached it: screened on the bench, re-measured by the verifier, given a short GPU search, built as keep-out CAD, and finally scored by the real requirement judges.

All morphologies

Every morphology the swarm has ideated, with the verifier's numbers where it re-measured one. Sorted by rank or gap, the dashed 3R-baseline row splits the list: everything above it beats the baseline. Gap: lower is better. In-band, reach and follow: higher is better. Click a column to sort.

Built designs over time, per requirement

Every design that was built as CAD and scored by the outside judges (the real requirements), placed at the time it was judged. Lines join the designs of one group in time order and never join 3-DOF to 4-DOF designs. The dashed green line is the pass line. Where the judging rules changed (dotted vertical line), the dots before it are faded and not joined to later ones: they are not comparable, and "best" counts only the current rules. Times in UTC.
